NAI 프롬프트 분류기

태그 뭉치를 콤마(,)로 구분해서 붙여넣으면 상위(그림체) / 하위(보강) / 네거티브 / 기타로 자동 분류해줘요. db.csv 카테고리 + quality-tags 화이트리스트 기반 휴리스틱이에요. 결과는 직접 편집할 수 있어요.

입력 — 분류할 태그 뭉치

상위 프롬프트 FRONT

그림체 / 스타일 — 작가 태그(artist:*), category=1, *_(style) 등

하위 프롬프트 BACK

보강 — db.csv category=5 (meta) + lighting/composition/medium 화이트리스트

네거티브 프롬프트 UC

부정 태그 — `-` prefix 또는 명시적 negative 키워드 화이트리스트

기타 / 직접 배치 OTHER

캐릭터(category=4) / 저작권(category=3) / 일반 태그(category=0) — 그 씬에서만 쓰는 것들. 보통 SDStudio의 '중간 프롬프트(씬별)' 영역으로 가요.

분류 기준 안내

• 상위 (FRONT): 모델이 가장 우선 인지 — 그림체 / 작가 / 조명 같은 *전체 톤*을 결정
• 하위 (BACK): 마지막에 붙는 보강 — quality booster, 매체, 배경 처리
• 네거티브 (UC): 보기 싫은 것들 — anatomy 오류, 저화질, 워터마크
• 기타: 씬마다 바뀌는 것들 (1girl, 의상, 포즈) — 그림체 프리셋과 따로 가야 swap이 의미 있어요
NAI weight 표기(1.5::tag::, {tag}) 안의 태그도 추출해서 분류해요. 분류 후 weight는 결과에서 제거되니, 필요하면 다시 박아주세요.
